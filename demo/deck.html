PathCheck

Can I take this class? Straight answers from the university's own catalog, schedule and policies, with the proof attached. When the data can't settle it, a human advisor does.

1 · The problem and who it hurts

Registration rules live in four places that don't talk to each other.

4

scattered sources

Course catalog, class schedule, degree pages, policy pages. Students have to join them in their heads.
300+

students per advisor

Advising appointments book out for weeks in registration season, right when the question is urgent.
1

online class, 3 credits

The most an F-1 student can count toward full time at WSU. Get it wrong and the cost is visa status, not just a semester.

Who: undergraduates and graduate students, especially international, first-generation and transfer students who don't know whom to ask. Generic chatbots make it worse by answering confidently without checking.

2 · The solution

Ask in plain words. Get a verdict per class, the reasons, and the source for each reason.

You can take it prerequisites met, sections listed

Not yet exactly which course is missing, and the path to it

Check with your advisor consent, standing or anything a transcript can't prove

  • Every reason has a source chip: catalog entry, schedule section or policy page, with the SQL query that found it.
  • Outdated pages are thrown out, not quoted.
  • Questions it can't settle become a short list to take to your advisor.
3 · Agent workflow

Five roles that check each other, not a straight pipeline.

PlannerReads the question: target classes, transcript, term, policy topics. Nemotron, fast lane.
ResearcherRuns SQL through Zetaris across 4 sources. Writes every row to the World Model with its query.
Prereq engineApplies the catalog's prerequisite text as exact rules. No model, so no guessing.
AnalystDrafts the answer in plain words, citing World Model evidence ids. Nemotron, deep lane.
CheckerRejects uncited, missing, outdated or contradicting claims. Judge model checks policy claims.
Loops and branches: class blocked → Researcher fetches the missing prerequisites, two levels deep · no policy text → Planner re-plans with broader terms · dated page → archived · claim rejected → back to the Analyst (up to 3 rounds), and anything still wrong is removed before the student sees it.
4 · Technical stack

Small, dependable, runs from a clean clone.

LayerWhat
DataZetaris Lightning: 4 REST tables (pathcheck.courses, sections, programs, policies), queried over the Zetaris REST SQL API
CognitionMeterless World Model engine: content-hash ids, append-only JSONL log, replay, provenance, agent attribution, context builder
ModelsMeterless Nightshift (OpenAI-compatible, provider contract) serving NVIDIA Nemotron on three lanes: fast, deep, judge
AppPython standard library only; Server-Sent Events stream every agent step to the page; 10 unit tests
FallbackSAMPLE_MODE=true: SQLite copy of the same data and recorded model replies, so judges can run it with no services
5 · How Zetaris and Meterless are used

Zetaris is where the sources meet. Meterless is how the agents remember and think.

Zetaris: the data layer

  • Four separately published sources, registered as Lightning REST tables in one Lightning database
  • Every agent lookup is SQL sent to Zetaris; the trace shows the query, row count and time
  • Joins catalog, schedule, programs and policies without a pipeline per source

Meterless: engine and runtime

  • World Model engine: shared, provenance-stamped state all five roles read and write; replayable from its log; tested
  • Nightshift: primary AI provider through the Meterless provider contract; per-agent lanes
  • NVIDIA Nemotron through Nightshift; the model id is logged for every request

Every trace line names its source: engine: zetaris on each query, and the Nemotron model id on each Nightshift request.

6 · What is unique

The model is never allowed to overrule the catalog.

  • Rules and models split the work: deterministic prerequisite logic decides eligibility; Nemotron explains it and reads policy prose.
  • The Checker overrides a wrong verdict and tells the Analyst why.
  • Every sentence traces to a World Model record, its Zetaris query and its source URL.
  • Honest by design: outdated pages are archived, and unprovable conditions go to an advisor.
